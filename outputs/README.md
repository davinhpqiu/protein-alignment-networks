# Outputs

Generated artefacts belong here:

- `figures/`: report-ready plots and diagrams.
- `tables/`: score matrices, summary statistics, and report tables.
- `graphs/`: serialised network edge lists or GraphML files.

Generated files are ignored by Git. Each important output should be reproducible
from a notebook or script and accompanied by recorded parameters.

The PF00042 score-correlation experiment writes to:

- `tables/pfam_pf00042_correlation/`: native method results, the canonical
  pair-aligned score table, Spearman correlations, and the run manifest;
- `figures/pfam_pf00042_correlation/`: native score distributions and pairwise
  score-correlation plots.

Reproduce the PF00042 score tables with
`scripts/run_pf00042_correlation.py`; the larger exploration is now handled by
`notebooks/03_large_scale_graph_exploration.ipynb`.

The complete pipeline writes separate method graphs to
`graphs/pfam_pf00042_pipeline/`, including GraphML, edge and node tables,
structural summaries, configurable quality-check results, and a run manifest.
These are generated by `scripts/build_method_graphs.py` and orchestrated in
`notebooks/02_pf00042_complete_pipeline.ipynb`.

The large-scale exploration writes to:

- `tables/pfam_clan_panel/`: 20,910 pair scores, collection definitions,
  scenario graph summaries, method edge overlap, and the run manifest;
- `figures/pfam_clan_panel/`: score-by-relationship, `top_k` sensitivity, and
  shared-layout graph figures;
- `graphs/pfam_clan_panel/`: representative Biopython and BLAST GraphML files
  plus edge, node, and summary tables.

These outputs are generated by
`notebooks/03_large_scale_graph_exploration.ipynb`. The default visual graph
uses `top_k=5`; it is an exploration setting, not a final project default.

The repeated-sampling experiment on the 960-domain panel writes to:

- `tables/pfam_large_panel_scores/`: all 460,320 master pair scores;
- `tables/pfam_large_panel_graph_recovery_initial/`: the first 50-replicate
  diagnostic slice;
- `tables/pfam_large_panel_graph_recovery_full/`: graphs over `top_k` and
  `percentile` rules, with a checksummed run manifest;
- `tables/pfam_large_panel_graph_recovery_matched_density/`: `target_density`
  graphs, including the `selection_shortfall` column that records where a
  method could not fill the requested edge budget;
- `tables/pfam_large_panel_graph_recovery_unweighted_reference/`: a focused
  reference-composition rerun where Louvain ignores native score weights;
- `tables/pfam_large_panel_score_permutation_null/`: a deterministic control
  that shuffles scores among pair identities within each collection;
- `tables/pfam_large_panel_graph_summary/`: rule, factor, and paired-method
  summaries, collection fingerprints, and the collection-uniqueness audit;
- `figures/pfam_large_panel/` and `figures/pfam_large_panel_full/`: the NMI
  distribution, density-mismatch, matched-density, and `top_k` sensitivity
  figures.

The recovery and unweighted runs are produced by
`scripts/run_resampled_graph_experiment.py`, the negative control by
`scripts/run_score_permutation_null.py`, and the summary directory by
`scripts/summarize_resampled_graph_experiment.py`. Exact realised counts are
read from their manifests and displayed in Notebook 03 rather than duplicated
here. Set `MPLCONFIGDIR` to a writable folder when running the summariser, or
Matplotlib may hang building its font cache and write tables without figures.

The `..._graph_recovery_smoke` and `..._graph_recovery_density_smoke`
directories are small verification runs kept only to show the rules behaved as
intended before each long run; they are not analysis inputs.
