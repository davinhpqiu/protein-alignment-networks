# Outputs

Generated artefacts belong here:

- `figures/`: report-ready plots and diagrams.
- `tables/`: score matrices, summary statistics, and report tables.
- `graphs/`: serialised network edge lists or GraphML files.

Generated files are ignored by Git. Each important output should be reproducible
from a notebook or script and accompanied by recorded parameters.

The PF00042 score-correlation experiment writes to:

- `tables/pfam_pf00042_correlation/`: native method results, the canonical
  pair-aligned score table, Spearman correlations, and the run manifest;
- `figures/pfam_pf00042_correlation/`: native score distributions and pairwise
  score-correlation plots.

Reproduce them with `scripts/run_pf00042_correlation.py` followed by
`notebooks/03_pf00042_data_exploration.ipynb`.

The complete pipeline writes separate method graphs to
`graphs/pfam_pf00042_pipeline/`, including GraphML, edge and node tables,
structural summaries, configurable quality-check results, and a run manifest.
These are generated by `scripts/build_method_graphs.py` and orchestrated in
`notebooks/02_pf00042_complete_pipeline.ipynb`.
